# Template Notion — Android Omni Cleaner

**Sezione documentale di ricerca GitHub, non sezione UI né negozio funzionante.** Il lotto di 12 esportazioni Notion (11 fonti distinte) è stato controllato nel [registro App Factory](https://github.com/riccardopinato/Idee-app-Archivi-riferimenti/blob/main/17-RICERCA-TEMPLATE-UX/LOTTO_NOTION_2026_11_09_12_ZIP.md).

## Template pertinenti

**Nessuno assegnato per ora.** Le funzioni dei template ricevuti non hanno ancora una corrispondenza verificata col Product Bible di Android Omni Cleaner; non inserire un planner, un catalogo di finanza o un tracker estraneo soltanto per riempire la sezione.

## Come classificare i prossimi invii

1. Confrontare il template con funzioni e limiti dell'app, e registrare una fonte centrale `TPLUX-REF-NNNN` unica.
2. Aggiungere una voce nell'indice e in `CATALOGO.json` solo se pertinente, con livello evidenza (E0–E3), stato RESEARCH, e idea di adattamento **originale e nativa per l'app**.
3. Non caricare ZIP, media, testo/immagini di terzi, dati personali o formule proprietarie nei GitHub pubblici. L'export prova solo la struttura, non il funzionamento del template.
4. Nessuna modifica automatica a codice, roadmap, Golden/CAP, billing, SKU, APK o dati locali; un eventuale store a €3,99 è ancora **idea**.
